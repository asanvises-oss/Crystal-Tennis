# crystal-watch

บอทเฝ้าดูสนามว่างของ Crystal Sports แล้วแจ้งเตือนทาง Telegram โดยรันวนต่อเนื่อง เช็กทุก 2 นาที (แก้ได้ที่ `interval_seconds`) ช่วง 08:00–23:00 (แก้ได้ที่ `active_hours`) นอกเวลานั้นเข้าเว็บแค่ชั่วโมงละครั้งเพื่อรักษา session (อ่านอย่างเดียว ไม่กดจอง)

## ตั้งค่า

1. **Telegram**: คุยกับ @BotFather พิมพ์ `/newbot` จะได้ token จากนั้นส่งข้อความอะไรก็ได้ให้บอทของคุณ
   แล้วเปิด `https://api.telegram.org/bot<TOKEN>/getUpdates` ดูเลข `chat.id`
2. **GitHub**: สร้าง repository แบบ Public แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`)
3. **Secrets**: ใน repository ไปที่ Settings → Secrets and variables → Actions แล้วเพิ่ม
   - `TG_TOKEN` token จาก BotFather
   - `TG_CHAT_ID` เลข chat id
   - `CRYSTAL_COOKIE` ล็อกอินเว็บสนามในคอม กด F12 → Network → รีเฟรชหน้า `/booking`
     คลิกรายการ `booking` → Request Headers → คัดลอกค่าหลัง `cookie:` ทั้งบรรทัด
4. **ทดสอบ**: แท็บ Actions → watch-courts → Run workflow

## เลือกวันและเวลา

แก้ `config.json` แต่ละรายการใน `watches` คือเงื่อนไขหนึ่งชุด

- `weekdays`: วันในสัปดาห์ (`mon` ถึง `sun`) หรือใช้ `"dates": ["2026-11-21"]` ระบุวันตรง ๆ
- `from` / `to`: ช่วงเวลาเริ่มเล่น เช่น `18:00` ถึง `21:00` คือช่อง 18:00, 19:00, 20:00
- `locs`: `LOC001` (Crystal Sports) หรือ `LOC002` (Crystal Sports G)
- `days_ahead`: เช็กล่วงหน้ากี่วัน

เมื่อบอทแจ้งว่าเข้าเว็บไม่ได้ มันจะลองต่อเองทุก 5 นาที ถ้าไม่กลับมาเอง ให้ล็อกอินใหม่แล้วอัปเดต `CRYSTAL_COOKIE` (มีผลภายในราว 30 นาที)

## จองอัตโนมัติด้วย Wallet

ตั้งค่าใน `auto_book` ของ `config.json`

- `enabled`: เปิดหรือปิดการจองอัตโนมัติ (ปิดแล้วบอทยังแจ้งเตือนตามปกติ)
- `dry_run`: `true` คือโหมดซ้อม ทำทุกขั้นแต่หยุดก่อนกดยืนยันการจอง `false` คือจองและจ่ายจริง
- `min_hours_ahead`: จองเฉพาะช่องที่เริ่มเล่นห่างจากตอนนั้นมากกว่ากี่ชั่วโมง (25 เพื่อให้ยังยกเลิกได้)
- `max_per_day` / `max_per_week`: จำนวนช่องสูงสุดที่บอทจองเองต่อวันเล่นและต่อสัปดาห์
- `max_price`: ไม่จองถ้าราคาต่อช่องเกินจำนวนนี้
- `accept_terms`: `true` คืออนุญาตให้บอทติ๊กยอมรับข้อตกลงการใช้บริการของสนามแทนคุณตอนกดยืนยัน ถ้าเป็น `false` บอทจะไม่จอง
- `reset`: ถ้าบอทแจ้งว่าผลการจองไม่ชัดเจน มันจะหยุดจองเอง ตรวจการจองแล้วเพิ่มเลขนี้ขึ้นหนึ่งเพื่อให้จองต่อ

บอทจองเฉพาะช่องที่ตรงกับ `watches` จ่ายด้วย Wallet เท่านั้น และไม่รู้จักการจองที่คุณทำเอง

## ข้ามบางวัน

พิมพ์หาบอทใน Telegram เช่น `ข้าม เสาร์ อาทิตย์` หรือ `ข้าม 20/11` บอทจะไม่หาและไม่จองวันนั้น พิมพ์ `ยกเลิกข้าม` เพื่อกลับมาหาตามปกติ
หรือใส่วันที่ใน `skip_dates` ของ `config.json` (รูปแบบ `2026-11-20`)
